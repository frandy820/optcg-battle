# 真人试玩验收包 — 航海王卡牌对战

> 候选版本：分支 `feature/rc-plus-polish`，commit `7e1f1c2`（2026-09-16）
> 性质：合并 master 前的人工试玩验收。此版本已通过全部自动化质量门禁（语法/引擎规则 90 项/构建/自检 42 项/端到端四模式/断网完整对局）与两轮真实点击流模拟。
> 试玩时长建议：**10 分钟以内**（两局）。

## 一、如何启动

**方式 A（最简单，双击即玩）**
直接双击打开：`F:\claudecode\test\optcg-battle\web\index.html`
（用 Chrome / Edge 打开；无需联网、无需安装任何东西。）

**方式 B（本地服务器，如果方式 A 打不开）**
```
cd F:\claudecode\test\optcg-battle\web
python -m http.server 8181
```
浏览器访问 `http://localhost:8181`

**清档重测首访体验（可选）**：浏览器按 F12 → Application（应用）→ Local Storage → 删除该地址下的条目 → 刷新页面，即可回到「第一次玩」的状态。

## 二、10 分钟试玩任务清单

**第一局 · 默认新玩家路径（约 5 分钟）**
1. 打开游戏，看新手引导是否出现；选择「看完引导」或「跳过」均可
2. 在大厅**不选任何船长**，直接点金色「出航！」——应能直接开局（有默认船长兜底）
3. 打一局完整对局：出手牌、点自己单位再点敌方发起攻击、对方打你时看响应面板的说明文字
4. 点一张灰色（不可出）手牌，看有没有告诉你为什么不能出
5. 打到胜负结算 → 点「再战一局」或「返回港口」

**第二局 · 连续状态路径（约 5 分钟）**
1. 回到大厅，**换一位船长**（点另一张船长卡），再出航
2. 对局中点顶部「说明」按钮，看完后分别试「点按钮关闭」和「按 Esc 关闭」
3. 趁对方回合乱点几下空白处、快速连点「结束回合」——看会不会出毛病
4. 对局中途**直接刷新页面（F5）**——回到大厅后应出现「继续上次对局」，点它看能否接着打
5. 把这一局打完，返回港口

**手机屏体验（可选，2 分钟）**：按 F12 → 点设备图标（Ctrl+Shift+M）→ 选 iPhone 12/13 Pro（390 宽）→ 重复上面任意一局。手牌多了需要**左右滑动**，注意是否有渐隐提示、顶部按钮是否还在。

## 三、重点观察的 12 个体验点

| # | 观察点 | 期望 |
|---|---|---|
| 1 | 首次打开 30 秒内 | 知道该干什么（引导/出航入口明显） |
| 2 | 不选船长直接出航 | 能正常开局，不会卡住或报错 |
| 3 | 「不能出的牌」 | 点了有文字说明原因（不是没反应） |
| 4 | 攻击操作 | 点自己单位后有高亮提示选目标；再点可取消 |
| 5 | 对方攻击时的响应面板 | 文字能看懂「阻挡/反击」是什么意思 |
| 6 | 回合流转 | 点「结束回合」后对方行动、然后轮回到你，不长时间卡住 |
| 7 | 胜负结算 | 结果明确，能顺畅再战或返回 |
| 8 | 连续两局 | 第二局没有上一局的残留（手牌/费用/计时异常） |
| 9 | 刷新续战 | 刷新后「继续上次对局」能恢复到刚才的局势 |
| 10 | 帮助面板 | 任何时候都能轻松关掉（按钮或 Esc） |
| 11 | 卡牌图片 | 加载失败时显示占位图案而不是破图/空白 |
| 12 | 手机窄屏（如试） | 结束回合、关帮助、选目标都还能点到；页面不会左右晃 |

## 四、反馈模板

发现问题请按此格式记录（一句话即可，不用写长）：

```
【操作步骤】我在……（做了什么）
【实际现象】画面……（看到了什么）
【以为应该】我预期……
【截图/录像】文件名：（如 shot-01.png）
【严重程度】阻断 / 明显不便 / 小瑕疵
```

- **阻断** = 玩不下去（卡死、按钮点不动、白屏）
- **明显不便** = 能玩但别扭（找不到入口、看不懂、误操作）
- **小瑕疵** = 视觉/文案类小问题

## 五、已知不阻塞的限制（无需重复反馈）

- 「难」档 AI 的对局平衡尚未做大样本校准（人机对战主路径是易/中两档）
- 手机窄屏（390px）下手牌超过约 8 张需要**左右滑动**查看（有渐隐提示，属设计取舍）
- 引导页「跳过教程」按钮视觉上不够突出（功能正常）
- DON!! 费用区以金色圆点显示，无常驻文字标签（引导和提示条里有说明）
- 战报（右侧日志）字号与密度偏小，长局可读性一般
- 音效/音乐：本版本无（后续版本考虑）
